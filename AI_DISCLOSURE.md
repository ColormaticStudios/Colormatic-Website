# Colormatic Website AI Disclosure

Most of this project was written by a human developer. The design language, text, and navigation were all created by a human.

This project uses AI as a tool to get the same work done, but quicker. Things like AI tab complete and inline assisting are much more commonly used than agents.

Agents are mostly used for generating logic that users don't see, stuff that is less artistic and more utility/tools. For example, the [RSS parser](src/lib/utils/rss.ts) or most of the [release build workflow](.gitea/workflows/release-build.yml).
